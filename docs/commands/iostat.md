
####  软件支持的功能清单

| **软件功能**                                          | **原有软件（iostat）** | **Rust 重写后的软件** | **是否包含单元测试** |
| ----------------------------------------------------- | ---------------------- | --------------------- | -------------------- |
| **无参数运行 iostat**                                 | 支持                   | 支持                  | 是                   |
| **iostat -c（只显示 CPU 使用情况）**                  | 支持                   | 支持                  | 是                   |
| **iostat -d（只显示设备使用情况）**                   | 支持                   | 支持                  | 是                   |
| **iostat interval count（按着指定间隔输出指定次）**   | 支持                   | 支持                  | 是                   |
| **iostat -f 和 iostat +f（指定文件目录）**            | 支持                   | 支持                  | 是                   |
| **iostat -g group_name {device}（分组输出设备信息）** | 支持                   | 支持                  | 否                   |
| **iostat -H（分组且只输出整体信息）**                 | 支持                   | 支持                  | 否                   |
| **iostat -o JSON（输出 JSON 格式）**                  | 支持                   | 支持                  | 是                   |
| **iostat --human（可读的格式输出）**                  | 支持                   | 支持                  | 是                   |
| **iostat --pretty（格式化输出）**                     | 支持                   | 支持                  | 是                   |
| **iostat -h（--human 和 --pretty 的结合）**           | 支持                   | 支持                  | 是                   |
| **iostat -N（提取设备映射信息）**                     | 支持                   | 支持                  | 是                   |
| **iostat --dec=0,1,2（指定小数点位数）**              | 支持                   | 支持                  | 是                   |
| **iostat -p ALL（输出所有分区信息）**                 | 支持                   | 支持                  | 是                   |
| **iostat -x（输出扩展统计信息）**                     | 支持                   | 支持                  | 是                   |
| **iostat -s（简短模式输出）**                         | 支持                   | 支持                  | 是                   |
| **iostat -y （忽略首次输出）**                        | 支持                   | 支持                  | 是                   |
| **iostat -z （只输出活跃的设备）**                    | 支持                   | 支持                  | 是                   |
| **iostat -t（输出时间戳）**                           | 支持                   | 支持                  | 是                   |
| **iostat -j（显示持久化设备名称）**                   | 支持                   | 支持                  | 否                   |
| **iostat -k（以KB/s为单位显示）**                     | 支持                   | 支持                  | 否                   |
| **iostat -m（以MB/s为单位显示）**                     | 支持                   | 支持                  | 否                   |

**注：`iostat -g` 需要指定组内的设备名称，因单测的机器设备名未知，所以没有添加指定测试，`iostat -H` 依赖`-g`，原因同理。`iostat -j`、`-k`、`-m` 选项功能简单，通过其他测试已间接验证。手动测试见补充功能对比验证**。
