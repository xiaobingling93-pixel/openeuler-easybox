## lspci功能对比验证报告

### 软件支持的功能清单

| 软件功能                                                     | 原有软件 | Rust重写后的软件 | 是否自动化测试 |
| ------------------------------------------------------------ | -------- | ---------------- | -------------- |
| -m, --machine 以机器可读的形式输出                           | 支持     | 支持             | 是             |
| -t, --tree 输出bus树                                         | 支持     | 支持             | 是             |
| -v, --verbose 详细输出                                       | 支持     | 支持             | 是             |
| -vv, -vvv 更详细的输出                                       | 支持     | 支持             | 是             |
| -k, --kernel 输出每个设备相关的内核模块和驱动                | 支持     | 支持             | 是             |
| -x, --hexdump 以十六进制输出config的标准部分                 | 支持     | 支持             | 是             |
| -xxx 以十六进制输出config的全部内容（root）                  | 支持     | 支持             | 是             |
| -xxxx 以十六进制输出config的4096 bytes的内容（root）         | 支持     | 支持             | 是             |
| -b, --bus-centric 以总线为中心的视图                        | 支持     | 支持             | 是             |
| -D, --domain 总是显示domain                                  | 支持     | 支持             | 否*            |
| -P, --path 输出bridge路径                                    | 支持     | 支持             | 是             |
| -PP 输出bus路径                                              | 支持     | 支持             | 是             |
| -n, --number 输出数字id                                      | 支持     | 支持             | 是             |
| -nn 同时输出文本和数字id                                     | 支持     | 支持             | 是             |
| -q, --dns 通过DNS查询未知设备                                | 支持     | 支持             | 是             |
| -qq 通过DNS查询未知设备后在本地重查                          | 支持     | 支持             | 是             |
| -Q, --qdns 通过DNS查询所有设备                               | 支持     | 支持             | 是             |
| -s, --slot `[[[[<domain>]:]<bus>]:][<slot>][.[<func>]]` 只输出与slots匹配的设备 | 支持     | 支持             | 是             |
| -d, --id `[<vendor>]:[<device> ][:<class>]`只输出特定id的设备 | 支持     | 支持             | 是             |
| -i, --db <file> 使用指定的数据库                             | 支持     | 支持             | 否*            |
| -p <file> 是在指定的modules.pcimap文件                       | 不支持   | 不支持           | 否             |
| -M, --map-mode 开启bus mapping模式                           | 支持     | 支持             | 是             |
| --help 显示此帮助信息并退出                                  | 支持     | 支持             | 否*            |
| --version 显示版本信息并退出                                 | 支持     | 支持             | 否*            |

注：

- 目前的linux与openEuler系统中不再有modules.pcimap这个文件，pciutils不是以这种方式获取内核模块信息
- Rust重写后的软件通过读取软链接的方式获取内核模块

### 软件自带用例对比验证

软件自带共17个测试点如下：

测试无参数输出，检测输出是否与原有软件一致

测试`-t、-t -v`参数，检测输出的树是否与原有软件一致

测试`-m`参数，检测输出是否与原有软件一致

测试`-v`参数，检测是否输出详细信息且正确

测试`-k`参数，检测是否输出内核模块与驱动

测试`-q、-qq、-Q`参数，检测DNS查询生成的输出是否与原有软件一致

测试`-M`参数，检测标准输出是否与原有软件一致

测试`-n、-nn`参数，检测输出是否与原有软件一致

测试`-x、-xxx、-xxxx`参数，检测输出是否与原有软件一致

测试`-b`参数，检测输出是否与原有软件一致

测试`-P`参数，检测输出是否与原有软件一致

测试`-d 8086:293e`，检测是否只输出匹配的设备且与原有软件一致

测试`-s 0:1`，检测是否只输出匹配的设备且与原有软件一致

测试组合参数`-q -s 0:1`，检测输出是否原有软件一致

测试组合参数`-m -d 8086:293e`，检测输出是否原有软件一致

测试非法参数`-1`，检测是否返回错误码`1`

**测试结果**

测试平台为openEuler22.03-LTS-SP1，cpu架构为aarch64。和Ununtu20.04 x86

测试的对照软件为pciutils version 3.8.0中的lspci，不同版本的输出可能有细微差异。

### 功能对比验证

1. 功能点1: 无参数输出
	- 测试方法：在测试环境中运行`easybox lspci`
	- 测试结果：输出所有设备的简略信息
2. 功能点: `-m`参数输出
	- 测试方法：在测试环境中运行``easybox lspci -m``
	- 测试结果：以机器可读的方式输出所有设备的简略信息
3. 功能点: `-t`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -t`与`easybox lspci -tv`
	- 测试结果：输出树形结构与节点附属信息
4. 功能点: `-v`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -v`与`easybox lspci -vvv`
	- 测试结果：输出详细的设备信息，包含内存，内核模块等信息
5. 功能点: `-k`参数输出
	- 测试方法：在测试环境中运行``easybox lspci -k``
	- 测试结果：输出设备的内核模块与驱动
6. 功能点: `-x`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -x`与``sudo easybox lspci -xxx`
	- 测试结果：以16进制输出config的内容
7. 功能点: `-b`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -b`
	- 测试结果：输出与原有软件一致
8. 功能点: `-D`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -D`
	- 测试结果：可以输出domain
9. 功能点: `-P`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -P`与`easybox lspci -PP`
	- 测试结果：输出子系统的路径
10. 功能点: `-n`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -n`与`easybox lspci -nn`
	- 测试结果：以数字ID的形式输出设备信息
11. 功能点: `-q`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -q -i no_file`与`easybox lspci -i no_file`，其中no_file不存在
	- 测试结果：前者可以通过DNS查询输出设备信息，后者只能输出ID
12. 功能点: `-Q`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -Q -i no_file`
	- 测试结果：可以通过DNS查询输出设备名
13. 功能点: `-s`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -s 0:1`
	- 测试结果：只输出00:01.x的设备信息
14. 功能点: `-d`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -d 8086:293e`
	- 测试结果：只输出device:class 为8086:293e的设备信息
15. 功能点: `-i`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -i no_file`与`easybox lspci -i pci.ids`，其中no_file不存在，pci.ids文件为pci数据库
	- 测试结果：前者只能以id的形式输出，后者可以输出设备信息
16. 功能点: `-M`参数输出
	- 测试方法：在测试环境中运行`easybox lspci -M`与
	- 测试结果：输出`Summary of buses`信息
