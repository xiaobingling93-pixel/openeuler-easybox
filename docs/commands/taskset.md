## taskset功能对比验证报告

### 软件支持的功能清单

| 软件功能                                 | 原有软件 | Rust重写后的软件 |
| ------------------------------------ | ---- | ---------- |
| taskset [选项]  掩码 命令 [参数]             | 支持   | 支持         |
| taskset [选项] -p [掩码] \<PID\>         | 支持   | 支持         |
| -a, --all-tasks 获取/设置给定进程的所有线程CPU亲和性 | 支持   | 支持         |
| -c, --cpu-list 使用CPU数字列表、范围表示掩码      | 支持   | 支持         |
| -p, --pid 对现有PID执行操作，不启动新任务          | 支持   | 支持         |
| -h, --help 显示程序的帮助信息                 | 支持   | 支持         |
| -V, --version 显示程序的版本信息              | 支持   | 支持         |

### 功能对比验证

1. 功能点1：使用指定的CPU亲和性掩码启动新进程
- 测试方法：在测试环境中运行命令`taskset 1 sleep 1`
- 测试结果：命令成功运行，新启动的进程仅在CPU0上运行。
2. 功能点2：使用指定的CPU亲和性列表启动新进程
- 测试方法：在测试环境中运行命令`taskset -c 0-1 sleep 1`
- 测试结果：命令成功运行，新启动的进程仅在CPU0、CPU1上运行。
3. 功能点3：根据PID查询已存在进程的CPU亲和性掩码
- 测试方法：在测试环境中运行命令`taskset -p 1`
- 测试结果：命令成功运行，输出PID为1的进程目前的CPU亲和性掩码。
4. 功能点4：根据PID查询已存在进程的CPU亲和性列表
- 测试方法：在测试环境中运行命令`taskset -pc 1`
- 测试结果：命令成功运行，输出PID为1的进程目前的CPU亲和性列表。
5. 功能点5：根据PID设置已存在进程的CPU亲和性掩码
- 测试方法：在测试环境中运行命令`taskset -p 2 $$`，其中`$$`为环境变量，表示测试程序的PID。
- 测试结果：命令成功运行，指定的进程仅在CPU0、CPU1上运行。
6. 功能点6：根据PID设置已存在进程的CPU亲和性列表
- 测试方法：在测试环境中运行命令`taskset -pc 0-3:2 $$`，其中`$$`为环境变量，表示测试程序的PID。
- 测试结果：命令成功运行，指定的进程仅在CPU0、CPU2上运行。
7. 功能点7：根据PID设置已存在进程所有子线程的CPU亲和性掩码
- 测试方法：首先测试程序启动若干新线程运行，然后运行命令`taskset -ap 2 $$`，其中`$$`为环境变量，表示测试程序的PID。
- 测试结果：命令成功运行，测试程序的所有线程仅在CPU0、CPU1上运行。
8. 功能点8：设置CPU亲和性失败时的错误处理
- 测试方法：在测试环境中运行命令`taskset -p 0 $$`，尝试修改测试程序的CPU亲和性掩码为0（非法值）。
- 测试结果：命令运行失败，CPU亲和性无法修改，返回错误信息后，以返回值1退出。
9. 功能点9：测试help和version参数
- 测试方法：在测试环境中运行`taskset --help`和`taskset --version`。
- 测试结果：命令运行成功，程序输出帮助信息与版本信息。
