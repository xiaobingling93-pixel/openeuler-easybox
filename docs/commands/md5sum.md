## md5sum功能对比验证报告
### 软件支持的功能清单
| 软件功能                                                             | 原有软件 | Rust重写后的软件 |
|----------------------------------------------------------------------|----------|------------------|
| -b, --binary 以二进制模式读取                                        | 支持     | 支持             |
| -c, --check 从给定文件中读取校验和并予以检查                         | 支持     | 支持             |
| --tag 创建一个 BSD 风格的校验和                                      | 支持     | 支持             |
| -t, --text 以纯文本模式读取（默认）                                  | 支持     | 支持             |
| -z, --zero 以 NUL 空字符而非换行符结束每一输出行，同时禁用文件名转义 | 支持     | 支持             |
| --ignore-missing 忽略缺失文件的情况                                  | 支持     | 支持             |
| --quiet 对于成功校验的文件不输出OK                                   | 支持     | 支持             |
| --status 不输出，以返回吗表示是否校验成功                            | 支持     | 支持             |
| --strict 对格式不正确的校验和以非0退出                               | 支持     | 支持             |
| -w, --warn 对格式不正确的校验和输出警告                              | 支持     | 支持             |
| --help 显示此帮助信息并退出                                          | 支持     | 支持             |
| --version 显示版本信息并退出                                         | 支持     | 支持             |

软件自带用例对比验证
软件自带共15个测试，分为test_md5sum_hash与test_md5sum_check，测试点如下：

测试无参数时通过标准输入字符串，检测输出是否与原有软件一致

测试无参数时通过标准输入进行规模较大的输入，检测是否正确运行并且输出是否与原有软件一致

测试输入文件参数时，检测输出是否与原有软件一致

测试进行大文件输入时，检测输出是否与原有软件一致

测试-b参数，检测输出是否与原有软件一致

测试--tag参数，检测输出是否与原有软件一致

测试--zero参数，检测标准输出是否与原有软件一致

测试-c参数时通过标准输入字符串，检测是否校验成功

测试-c check3.txt参数，检测是否校验成功check3.txt文件的内容

测试check文件中含缺失文件的情况下，是否含--ignore-missing参数时标准错误为空，不含--ignore-missing时标准错误非空

测试校验成功时的是否含--quiet参数时标准输出为空，不含--quiet时标准输出非空

测试是否含--status参数时标准输出为空，校验成功时返回0，校验失败返回1，不含--quiet时标准输出非空，返回0

测试check文件中格式不正确的情况下，是否含--warn参数时标准错误非空，不含--warn时标准错误为空

测试check文件中格式不正确的情况下，是否含--strict参数时败返回1，不含--strict时返回0

测试标准输入和输入文件混合的情况下，输出是否与原有软件一致

### 测试结果

测试平台为openEuler22.03-LTS-SP1，cpu架构为amd64

功能对比验证
功能点: 无参数情况
测试方法：在测试环境中运行sha256sum
测试结果：输出通过标准输入读取的数据的SHA256校验和，与原有软件一致。
功能点: -b 参数
测试方法：在测试环境中运行sha256sum -b filename
测试结果：输出文件的SHA256校验和，以二进制模式读取，与原有软件一致。
功能点: -c 参数
测试方法：在测试环境中运行sha256sum -c checkfile
测试结果：从checkfile中读取校验和并进行校验，输出校验结果，与原有软件一致。
功能点: --tag 参数
测试方法：在测试环境中运行sha256sum --tag filename
测试结果：输出BSD风格的SHA256校验和，与原有软件一致。
功能点: -t 参数
测试方法：在测试环境中运行sha256sum -t filename
测试结果：以文本模式读取文件并输出SHA256校验和，与原有软件一致。
功能点: -z 参数
测试方法：在测试环境中运行sha256sum -z filename
测试结果：以NUL字符而非换行符结束每一输出行，输出SHA256校验和，与原有软件一致。
功能点: --ignore-missing 参数
测试方法：在测试环境中运行sha256sum --ignore-missing -c checkfile
测试结果：忽略缺失文件的情况，校验成功时标准错误为空，不含此参数时标准错误输出某文件不存在。
功能点: --quiet 参数
测试方法：在测试环境中运行sha256sum --quiet -c checkfile
测试结果：对于成功校验的文件不输出OK，与原有软件一致。
功能点: --status 参数
测试方法：在测试环境中运行sha256sum --status -c checkfile
测试结果：不输出结果，以返回码表示是否校验成功，与原有软件一致。
功能点: --strict 参数
测试方法：在测试环境中运行sha256sum --strict -c checkfile
测试结果：对格式不正确的校验和以非0退出，与原有软件一致。
功能点: -w 参数
测试方法：在测试环境中运行sha256sum -w -c checkfile
测试结果：对格式不正确的校验和输出警告，与原有软件一致。
功能点: --help 参数
测试方法：在测试环境中运行sha256sum --help
测试结果：显示帮助信息并退出。
功能点: --version 参数
测试方法：在测试环境中运行sha256sum --version
测试结果：显示版本信息并退出。
